# GraphDB Benchmark

## Project Overview

This project is used to test and measure the performance of queries in a graph database.

The project uses movie data stored in a CSV file. The data is loaded into CognoDB and different Cypher queries are executed on the database. The execution time of the queries is recorded and used to create a graph for comparison.

## Technologies Used

- Python
- CognoDB
- Neo4j Python 
- Pandas
- Matplotlib
- VS Code
- GitHub
